# Homework 16 - Консольный сетевой чат с ролями и командой /kick

## Доработка
1. Добавлены роли пользователей: `USER`, `ADMIN`
2. Для `ADMIN` добавлена команда `/kick username` для отключения пользователей

## Запуск

### 1. Запуск сервера (в первом терминале)
```bash
cd homework-16/server/src/main/java
javac ru/otus/chat/server/*.java
java ru.otus.chat.server.ServerApp
```

### 2. Запуск клиента 1 (во втором терминале)
```bash
cd homework-16/client/src/main/java
javac ru/otus/chat/client/*.java
java ru.otus.chat.client.ClientApp
```

### 3. Запуск клиента 2 (в третьем терминале)
```bash
cd homework-16/client/src/main/java
java ru.otus.chat.client.ClientApp
```

## Использование

### Роли
При подключении каждый клиент получает роль:
- **Первый подключившийся клиент** → `ADMIN`
- **Все остальные клиенты** → `USER`

Это гарантирует, что всегда будет хотя бы один администратор для тестирования команды `/kick`.

### Команды

#### Публичные сообщения
```
Привет всем!
```

#### Личные сообщения (`/w`)
```
/w user54321 Привет!
```

#### Отключение пользователя (`/kick`) - только ADMIN
```
/kick user12345
```

#### Выход
```
/exit
```

## Пример работы

**Клиент 1 (user50009 - ADMIN):**
```
Вы подключились с ником: user50009
Ваша роль: ADMIN
/kick user50010
Пользователь user50010 был отключен администратором user50009
```

**Клиент 2 (user50010 - USER):**
```
Вы подключились с ником: user50010
Ваша роль: USER
Вы были отключены администратором user50009
```

## Что добавлено

1. Enum `Role` с ролями `USER` и `ADMIN`
2. Поле `role` в классе `ClientHandler`
3. Метод `kickUser()` в классе `Server`
4. Обработка команды `/kick` в классе `ClientHandler`
5. Проверка прав: только `ADMIN` может использовать `/kick`
6. Уведомление всех пользователей об отключении
