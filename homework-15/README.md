# Homework 15 - Консольный сетевой чат с личными сообщениями

## Доработка
Добавлена возможность отправки личных сообщений через команду `/w nick сообщение`

## Запуск

### 1. Запуск сервера (в первом терминале)
```bash
cd homework-15/server/src/main/java
javac ru/otus/chat/server/*.java
java ru.otus.chat.server.ServerApp
```

### 2. Запуск клиента 1 (во втором терминале)
```bash
cd homework-15/client/src/main/java
javac ru/otus/chat/client/*.java
java ru.otus.chat.client.ClientApp
```

### 3. Запуск клиента 2 (в третьем терминале)
```bash
cd homework-15/client/src/main/java
java ru.otus.chat.client.ClientApp
```

## Использование

### Публичные сообщения
Просто напишите текст и нажмите Enter — сообщение увидят все:
```
Привет всем!
```

### Личные сообщения
Используйте команду `/w nick сообщение`:
```
/w user54321 Привет, это личное сообщение!
```

Где:
- `user54321` — ник получателя
- `Привет, это личное сообщение!` — текст сообщения

### Выход
```
/exit
```

## Пример работы

**Клиент 1 (user12345):**
```
Вы подключились с ником: user12345
/w user54321 Привет!
```

**Клиент 2 (user54321):**
```
Вы подключились с ником: user54321
[Личное от user12345]: Привет!
```
