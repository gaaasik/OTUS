# Homework 19 - Работа с обобщениями (Generics)

## Описание

Реализация коробок для фруктов с использованием **Java Generics**.

---

## Структура классов

### `Fruit` (абстрактный класс)
Базовый класс для всех фруктов.
- `weight` — вес фрукта

### `Apple extends Fruit`
Класс яблока.
- Вес: **1.0**

### `Orange extends Fruit`
Класс апельсина.
- Вес: **1.5**

### `Box<T extends Fruit>`
Обобщенный класс коробки для фруктов.

**Методы:**
- `add(T fruit)` — добавить фрукт в коробку
- `weight()` — вес коробки (сумма весов всех фруктов)
- `compare(Box<?> other)` — сравнить вес с другой коробкой (true если равны)
- `pourTo(Box<T> other)` — пересыпать фрукты в другую коробку того же типа
- `count()` — количество фруктов в коробке

---

## Особенности реализации

✅ Использован **Generic тип** `<T extends Fruit>` — коробка только для фруктов  
✅ Метод `compare` принимает `Box<?>` — можно сравнивать коробки с разными типами  
✅ Метод `pourTo` принимает `Box<T>` — пересыпать можно только в коробку того же типа  
✅ Вес яблока: **1.0**, вес апельсина: **1.5**  
✅ Сравнение веса через `Math.abs` с точностью 0.0001
