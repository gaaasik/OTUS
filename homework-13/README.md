# Homework 13 - Клиент-серверное приложение "Калькулятор"

## Описание
Клиент-серверное приложение для выполнения математических операций через сеть.

## Запуск

### 1. Компиляция
```bash
cd homework-13/src/main/java
javac ru/otus/hw13/*.java
```

### 2. Запуск сервера (в первом терминале)
```bash
cd homework-13/src/main/java
java -cp . ru.otus.hw13.Server
```

### 3. Запуск клиента (во втором терминале)
```bash
cd homework-13/src/main/java
java -cp . ru.otus.hw13.Client
```

## Использование

После подключения клиента:
1. Клиент получает список доступных операций: `+, -, *, /`
2. Введите выражение в формате: `число операция число`
   - Пример: `10 + 5`
   - Пример: `20 / 4`
3. Сервер вычисляет результат и отправляет клиенту
4. Для выхода введите: `exit`

## Примеры

```
Введите выражение: 10 + 5
Результат: 15.0

Введите выражение: 20 * 3
Результат: 60.0

Введите выражение: 100 / 4
Результат: 25.0

Введите выражение: exit
Отключение от сервера
```
